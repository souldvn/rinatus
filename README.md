# Портфолио Рината Мусина

React 19 + TypeScript + Vite. Семь страниц по предоставленным PDF, без серверной части.

## Локальный запуск

Требуется Node.js 22.12+ (или совместимая актуальная LTS-версия).

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

`dist/` — готовая статическая сборка. `npm run preview` используется для локальной проверки, а не как production-сервер.

Сайт рассчитан на корень домена. При размещении в подпапке нужно задать `base` в Vite и `basename` в BrowserRouter, а также адаптировать абсолютные пути ресурсов.

- **Vercel:** build command `npm run build`, output directory `dist`. SPA-переходы настроены в `vercel.json`.
- **Netlify / Cloudflare Pages:** build command `npm run build`, output directory `dist`. Правило возврата `index.html` находится в `public/_redirects` и попадает в сборку.
- **Nginx:** скопировать содержимое `dist/` в web root и использовать пример `nginx.conf`. Для домена настроить DNS и HTTPS на выбранном сервере.

Перенаправление неизвестных URL на `index.html` нужно для прямого открытия и обновления страниц кейсов. Неизвестные маршруты показывают экран 404 внутри приложения.

## Структура

- `src/content.ts` — тексты проектов, кейсов, порядок разделов и изображения.
- `src/main.tsx` — маршруты, страницы, scrollspy и просмотрщик изображений.
- `src/styles.css` — адаптивная сетка, типографика и состояния.
- `src/dimensions.json` — размеры изображений для резервирования места до загрузки.
- `public/assets/` — локальные WebP-изображения из PDF.

## Маршруты

`/`, `/projects`, `/projects/bank`, `/projects/bank/case/1`, `/projects/bank/case/2`, `/projects/bi`, `/projects/bi/case/1`.

На широком экране меню кейса закреплено слева. На экранах до 900 px меню разделов и кнопки «Предыдущий кейс» / «Следующий кейс» скрыты; в подвале остаются контакты. Активный раздел определяется по прокрутке; заголовки доступны по URL-якорю.

Изображения открываются в модальном окне: увеличение до 500%, кнопки +/−, колесо мыши, двойной клик, pinch-жест и перемещение. Закрытие — крестик, свободный фон или Escape. Фокус удерживается нативным dialog и возвращается к исходной кнопке.

Карточки проектов целиком являются ссылками. Контакты установлены из задания. CV намеренно оставлен текстом без ссылки; добавить ссылку можно в `SocialLinks`.

Изображения интерфейсов сохраняют исходное размытие и обезличивание из PDF. Тексты перенесены с исправлением технических артефактов PDF и явных опечаток.

Сайт опубликован на Vercel: https://rinatdesign.vercel.app. Проект: `souldvns-projects/rinatdesign`. Собственный домен не подключён.

Подключён репозиторий GitHub `souldvn/rinatus`: изменения в production-ветке `main` публикуются автоматически после `git push`.

Повторная публикация из корня проекта после входа в аккаунт Vercel:

```sh
npx vercel@latest deploy --prod
```

Настройки сборки и SPA-маршрутов сохранены в `vercel.json`. `.vercelignore` исключает временные файлы и локальные артефакты из загрузки.

## Типографика и проверка

Helvetica Neue из предоставленного архива подключён локально через `@font-face`: 400 (Roman), 500 (Medium), 700 (Bold), с кириллицей. OTF конвертированы в WOFF2; файлы и исходный copyright находятся в `public/fonts/`. Кегль всех существующих подвалов — 26 px, включая мобильные версии.

Главная и проекты используют высоту viewport без прокрутки на ПК. Мобильная главная скрывает локацию; расстояние между «Проекты» и стрелкой — 16 px. Изображения кейсов и оверлея скруглены на 8 px, светлые интерфейсы имеют рамку. Экспортные поля диаграмм отсекаются компонентом `PictureSurface`, исходные файлы сохранены.

`node --test tests/navigation.test.ts` (Node.js 22.18+ или 24) проверяет подсветку короткого «Результата» перед «Выводами», переходы по пунктам и обратную прокрутку.
